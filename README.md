# oxidized-nextjs-media-player

This is the a simple [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).  It is meant to demo the [oxidized-media-player](https://fctc-gitea-server.fly.dev/Davidian1024/oxidized-media-player).

## Running Locally

1. Clone this repo

2. Install NPM by following the directions located here: https://nodejs.org/en/download

3. Install dependencies: `npm i`

4. Build [oxidized-media-player](https://fctc-gitea-server.fly.dev/Davidian1024/oxidized-media-player).  Be sure to clone it into the same directory you cloned this one into.  The WASM it builds should end up in the wasm directory within this repo.

5. Run this Next.js app: `npm run dev`
